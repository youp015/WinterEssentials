# WinterEssentials

Simpele Essentials plugin, voor jouw smp het idee is dat het zowel voor vriendensmp's simpel is om optezetten.
Maar ook voor de grotere spelers die deze features aan hun webshop willen toevoegen enzoiets

## Installatie
1. Download de plugin (`WinterEssentials-1.0.0.jar`).
2. Plaats het bestand in de `plugins/` map van je server.
3. Herstart de server.

## Commands & Permissions

| Command | Permissie | Omschrijving |
| :--- | :--- | :--- |
| `/trash` | `winteressentials.command.trash` | trash GUI |
| `/repair [hand\|all]` | `winteressentials.command.repair.hand` / `.all` | repear items |
| `/feed [speler]` | `winteressentials.command.feed` / `.others` | Herstel food & saturation |
| `/craft` | `winteressentials.command.craft` | Virtual craftingtabel |
| `/anvil` | `winteressentials.command.anvil` | Virtual anvil |
| `/grindstone` | `winteressentials.command.grindstone` | Virtual grindstone |
| `/stonecutter` | `winteressentials.command.stonecutter` | virtual stonecutter |
| `/cartography` | `winteressentials.command.cartography` | virtual cartography |
| `/smithing` | `winteressentials.command.smithing` | Virtuak smithingtable |
| `/loom` | `winteressentials.command.loom` | Virtual Loom |
| `/enderchest` | `winteressentials.command.enderchest` | Open enderchest |
| `/pv <1-99>` | `winteressentials.command.vault` | Personal vault |
| `/sethome [naam]` | `winteressentials.command.sethome` | Zet een home |
| `/home [naam]` | `winteressentials.command.home` | Teleporteer naar home |
| `/delhome <naam>` | `winteressentials.command.delhome` | Verwijder een home |
| `/homes` | `winteressentials.command.homes` | Lijst van al je homes |
| `/we reload` | `winteressentials.admin.reload` | reload config |

## Limieten & Bypasses (Luckperms dingetje)
- Homes limiet: `winteressentials.homes.<aantal>`
- Vaults limiet: `winteressentials.vaults.<aantal>`
- Cooldown bypass: `winteressentials.bypass.cooldown`
- Teleport delay bypass: `winteressentials.bypass.teleportdelay`
